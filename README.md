# 大一 C++ 大作业：矩阵对战游戏

> 课程：大一 C++ 程序设计大作业
> 小组成员：薄闻乐、魏舟、尹杨阳

## 项目简介

一个 Windows 桌面双人对战小游戏，使用 C++ 与 Win32 GDI 实现图形界面。

每枚棋子对应一个 4×4 矩阵。棋子相遇时比较行列式大小决定胜负，玩家也可以使用矩阵技能（加 E、减 E、转置、求逆、对角化）改变棋子，因此“矩阵”既是棋盘上的战斗力，也是可操作的策略资源。

## 玩法规则

- 棋盘为 5×5，双方各 10 枚棋子：编号 1~10 属于玩家 1，11~20 属于玩家 2。
- 双方轮流行动，每次可以移动棋子、使用技能或结束回合。
- 棋子只能垂直或水平直线移动，3 号和 18 号棋子不能移动。
- 同方棋子相遇会合并，矩阵相加。
- 异方棋子相遇比较行列式的绝对值，大者获胜，小者被移除，相等则同归于尽。
- 一方剩余棋子少于 3 枚时，比较 3 号与 18 号棋子的行列式决定胜负。
- 主动点击“结束游戏”按钮时，按双方剩余棋子数判定胜负。

## 技能

| 技能 | 效果 |
| --- | --- |
| 加 E | 棋子矩阵加上单位矩阵 E |
| 减 E | 棋子矩阵减去单位矩阵 E |
| 转置 | 棋子矩阵转置 |
| 求逆 | 棋子矩阵求逆（矩阵不可逆时提示） |
| 对角化 | 对棋子矩阵做高斯消元，化为上三角矩阵 |

每种技能每位玩家只能使用一次。

## 代码结构

`version2.2.cpp` 单文件实现，主要分为三部分：

- **Matrix 类**：4×4 矩阵的存储与运算，包括用高斯消元实现的对角化、行列式、秩、转置、求逆，以及 `+`、`-`、`*`、`>>`、`<<` 运算符重载。
- **游戏逻辑**：`initGame` 初始化棋盘与随机棋子矩阵，`movePiece` 处理移动、合并与对战，`useSkill` 处理技能，`endTurn` 切换回合。
- **界面绘制**：`drawGame`、`drawButtons` 使用 GDI 绘制棋盘、棋子和按钮，`WndProc` 处理鼠标与窗口消息。

## 编译与运行

用 Dev-C++ 打开 `矩阵对战.dev` 直接编译，或使用 MinGW：

```bash
g++ version2.2.cpp -o 矩阵对战.exe -std=c++11 -mwindows
```

`rules.txt` 需要与程序位于同一目录（“查看规则”按钮会读取它）。也可以直接运行仓库中的 `矩阵对战.exe`。
