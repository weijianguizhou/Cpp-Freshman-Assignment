## 期末大作业：矩阵对战游戏

一个 Windows 桌面双人对战游戏，使用 C++ 与 Win32 GDI 实现图形界面。每枚棋子对应一个 4×4 矩阵，棋子相遇时比较行列式大小决定胜负，也可以用加 E、减 E、转置、求逆、对角化等矩阵技能改变棋子。

- 小组成员：薄闻乐、魏舟、尹杨阳
- 详细说明（玩法规则、代码结构、编译方式）：[大作业/README.md](大作业/README.md)
- 编译：

```bash
g++ version2.2.cpp -o 矩阵对战.exe -std=c++11 -mwindows
```

## 各目录说明

### 第一学期

`源码/` 中每个 `.cpp` 是一个独立小程序，覆盖：

- 顺序、分支与循环：九九乘法表、成绩等级评定、猜数字、调和级数、自增自减练习
- 函数与递归：阶乘、汉诺塔、斐波那契、递归求组合数
- 数组与字符串：矩阵转置、对角线交换、折半查找、字符串逆序与排序、统计字符
- 指针与结构体：二级指针访问二维数组、指针求串长与串拷贝、结构体工资条

## 编译与运行

- 单个练习文件（多数使用 `bits/stdc++.h`）：

```bash
g++ 文件名.cpp -o 文件名.exe -std=c++11
```

- 期末大作业（Windows 图形界面程序）：

```bash
g++ version2.2.cpp -o 矩阵对战.exe -std=c++11 -mwindows
```

- 源码多为 **GBK 编码**，用 VS Code 打开时若中文注释乱码，请设置 `"files.encoding": "gbk"`。
- 仓库中的 `.exe` 均为本地编译产物，可直接运行；Visual Studio 的 `.vs`、`x64`、`*.obj`、`*.pdb` 等缓存已清理，并由 `.gitignore` 排除。
