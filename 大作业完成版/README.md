# 矩阵对战游戏（完成版）

> 大一 C++ 大作业的整理重构版本：CMake 工程 + 缺陷修复
> 小组成员：薄闻乐、魏舟、尹杨阳

在原版 `大作业/` 的基础上，这一版把工程改成 CMake 组织，把矩阵运算拆到独立的
`Matrix` 类文件中，并修复了原版若干会影响游玩的缺陷。玩法与规则保持不变。

## 与初版的区别

### 修复的问题

| 问题 | 初版表现 | 本版处理 |
| --- | --- | --- |
| 技能按钮不刷新 | 点“使用技能”后按钮区不重绘，看不到技能按钮 | 每次点击后统一重绘，按钮立即出现 |
| 求逆失败污染棋子 | 矩阵不可逆时，把上一次残留的逆矩阵写进棋子 | 求逆改为高斯-约当消元并返回是否成功；失败时提示且不消耗技能、不结束回合 |
| 结束判定被覆盖 | 棋子数不足 3 判定结束后，`endTurn()` 又把状态改回“选择棋子”，游戏继续 | 判定结束后直接返回，不再切换回合 |
| 按钮与棋盘重叠 | 第一排按钮 y=300，与棋盘最后一行（y 到 310）重叠 10px | 按钮下移到 y=330 / 375，与棋盘完全分离 |
| 一次点击触发两处 | 点按钮时，同一坐标又进入棋盘点击逻辑 | 命中按钮后不再处理棋盘 |
| 关闭规则窗口退出程序 | 规则窗口收到 `WM_DESTROY` 后 `PostQuitMessage`，整个程序结束 | 只销毁规则窗口本身 |
| 窗口类重复注册 | 每次点“查看规则”都重新 `RegisterClass`，第二次起失败 | 两个窗口类在 `WinMain` 中统一注册一次 |
| 行列式符号错误 | 消元换行后没有翻转符号 | 部分主元消元，换行时 `det = -det` |
| 秩计算错误 | 遇到第一个零对角元就 `break` | 化为阶梯形后统计非零行数 |
| 浮点零判断 | 用 `!= 0.0` 判断，容易误判 | 统一使用 `EPS = 1e-9` |
| 主元过小 | 直接拿当前行做主元，除以接近 0 的数 | 每列选取绝对值最大的元素作为主元 |
| rules.txt 找不到 | 只按当前工作目录读取，从其他目录启动就读不到 | 优先按可执行文件所在目录读取，再退回当前目录 |
| 结束游戏即退出 | 点“结束游戏”直接 `PostQuitMessage`，看不到结果 | 在棋盘上显示结果面板，窗口保留可继续查看 |
| 未选棋子无响应 | 点“查看信息 / 移动棋子 / 技能”没有任何提示 | 统一提示“请先选择一个棋子” |

### 结构调整

- 矩阵运算从单文件里拆出为 `src/Matrix.h` / `src/Matrix.cpp`，游戏逻辑与界面留在 `src/main.cpp`。
- 构建交给 CMake：输出目录、`rules.txt` 自动复制都由 `CMakeLists.txt` 管理。
- 去掉无意义的“本回合已操作”标记（每个操作都会结束回合，该标记永远为 false）。

## 构建

需要 CMake 3.15 以上，以及 Visual Studio 或 MinGW 之一。

Visual Studio（推荐，支持中文路径）：

```bash
cmake -S . -B build -G "Visual Studio 18 2026" -A x64
cmake --build build --config Release
```

生成的可执行文件位于 `build/Release/矩阵对战.exe`。

MinGW：

```bash
cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

使用 MinGW Makefiles 时，请把工程放在纯英文路径下：`mingw32-make` 无法正确处理含中文的绝对路径。

## 运行

直接运行 `矩阵对战.exe` 或 `build/Release/矩阵对战.exe` 即可，`rules.txt` 会自动被复制到可执行文件旁边。

## 玩法规则

- 棋盘 5×5，双方各 10 枚棋子：1~10 属于玩家 1，11~20 属于玩家 2。
- 棋子只能垂直或水平直线移动，3 号与 18 号棋子不能移动。
- 同方棋子相遇合并，矩阵相加。
- 异方棋子相遇比较行列式绝对值，大者获胜；相等则同归于尽。
- 一方剩余棋子少于 3 枚时，比较 3 号与 18 号棋子的行列式决定胜负。
- 主动“结束游戏”时，按双方剩余棋子数判定胜负。

## 技能

| 技能 | 效果 |
| --- | --- |
| 加 E | 棋子矩阵加上单位矩阵 |
| 减 E | 棋子矩阵减去单位矩阵 |
| 转置 | 棋子矩阵转置 |
| 求逆 | 高斯-约当消元求逆，不可逆时失败且不消耗技能 |
| 对角化 | 高斯消元化为上三角矩阵 |

每种技能每位玩家只能使用一次，使用技能同样会结束当前回合。

## 编码说明

源码以 GBK 保存，并在 CMake 中指定了源字符集与执行字符集（MSVC 用 `/source-charset:.936`，MinGW 用 `-finput-charset=GBK`），以保证 `TextOutA`、`MessageBoxA` 等 ANSI 接口能正确显示中文。用 VS Code 查看时请设置 `"files.encoding": "gbk"`。
